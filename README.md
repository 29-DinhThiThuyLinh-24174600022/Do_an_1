# NYPD Stop, Question and Frisk Data Analysis

## Giới thiệu

Đây là đồ án phân tích dữ liệu NYPD Stop, Question and Frisk (SQF).

Mục tiêu của đồ án là phân tích hoạt động dừng, hỏi và kiểm tra của cảnh sát New York, tập trung vào mối quan hệ giữa sắc tộc và các quyết định kiểm tra.

## Dataset

Dữ liệu được sử dụng từ Kaggle:

NYPD Stop, Question and Frisk Data - 2012

Nguồn dữ liệu:
https://www.kaggle.com/datasets/vanessaponce/nypd-stop-question-and-frisk-2012

## Nội dung phân tích

- Làm sạch và tiền xử lý dữ liệu
- Phân tích đặc điểm dữ liệu
- Phân tích theo Race và Sex
- Phân tích mối quan hệ giữa Race và Frisked
- Phân tích mối quan hệ giữa Race và Searched
- Phân tích Arrest
- Kiểm định Chi-square
- Trực quan hóa dữ liệu

## Nguồn dữ liệu

Dataset gốc được cung cấp bởi Kaggle.

GitHub repository này được sử dụng để lưu trữ tài liệu, mã nguồn và kết quả phân tích của đồ án.
